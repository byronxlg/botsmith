Paid API, for agents

x402 data services

Real-time market signal for trading agents.

Every endpoint answers the same question: what is the market doing right now. What it is saying on X, what it expects on Polymarket, and what to do about it: a decision model that turns a state and a question into a calibrated probability.

An agent calls the URL, gets an HTTP 402 with the price, pays in USDC on Base, and gets JSON back. No account, no API key, no subscription.

Open x402.botsmith.dev On Agentic Market

The machine-readable catalog carries the schema, an example and the price for every route.

Three ways to connect an agent

From any HTTP client

Read the catalog, call a route, pay the 402. The x402 client libraries sign the payment for you.

curl https://x402.botsmith.dev/catalog

As MCP tools

The botsmith-mcp server reads the catalog when it starts and exposes each route as a tool, paying per call from a wallet you control. Works with Claude Desktop, Claude Code and any MCP client.

{
  "mcpServers": {
    "botsmith": {
      "command": "npx",
      "args": ["-y", "botsmith-mcp"],
      "env": {
        "BOTSMITH_PRIVATE_KEY": "0x..."
      }
    }
  }
}

Through the Bazaar

Every route in the catalog is indexed in the x402 Bazaar, Coinbase's discovery layer, so an agent that searches it finds botsmith on its own. Humans can browse the same listing on Agentic Market. Coinbase's wallet skills give an agent the search and the payment in one install.

npx skills add coinbase/agentic-wallet-skills

Terminal app, open source

polymarket-tui

Polymarket in your terminal.

Browse markets, watch live order books and trades, chart prices, track your portfolio and P&L, follow traders, and place orders without leaving the terminal. Python, built on Textual, MIT licensed.

uv tool install polymarket-tui
Open polymarket-tui Source on GitHub

Also on PyPI and Homebrew (brew install byronxlg/tap/polymarket-tui).

Web app, free to use

tryai

Try AI models in the browser, free.

Two tools, no sign-up. The Semantic Similarity Calculator scores how close two texts are in meaning, not in word overlap. Try Jev is a playground for TypeSafe's Jev decision model, free while the sponsored pool lasts.

Open tryai

Command-line tool, open source

skillfold

A declarative skill manager for Claude Code, Codex and Cursor.

Declare the skills your agents use in one YAML file, pin exact revisions in a lockfile, and install them the same way on every machine and for every teammate.

npm install -g skillfold
